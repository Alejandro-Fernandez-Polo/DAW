# Design Folder

This folder contains various web development practice projects for coursework. Each subfolder represents a different assignment or practice, showcasing HTML, CSS, JavaScript, and asset management skills. Below is an overview of the contents:

## Practice2
**Topic:** Webpage for a biopark, showcasing its attractions, facilities, and conservation efforts.
**WEB/**: Contains multiple HTML pages:
	- `index.html`: Homepage introducing the biopark, its mission, and main attractions.
	- `contacto.html`: Contact information and a form for visitors to reach out or request information.
	- `instalaciones.html`: Details and photos of the biopark's facilities, such as animal habitats, visitor areas, and amenities.
	- `conservacion.html`: Information about the biopark's conservation programs, environmental initiatives, and educational activities.
Each page has its own CSS file for styling. The project includes folders for images (`Fotos/`) and logos (`Logo/`).

## Practice3
**Topic:** Restaurant website with menu and team information.
**web/**: Features several HTML pages:
	- `index.html`: Homepage for the restaurant.
	- `contact.html`: Contact details and form.
	- `menu.html`: Menu offerings with descriptions and prices.
	- `team.html`: Information about the restaurant staff.
Each page is styled with its own CSS file. The project uses a JavaScript file (`functions.js`) for interactive features and an `img/` folder for images.

## Practice4
**Topic:** Webpage simulating the United States tourist office.
**WEB/**: Contains HTML pages:
	- `index.html`: Welcome page with an overview of the tourist office and its services for visitors to the United States.
	- `contact.html`: Contact information and a form for inquiries about travel, visas, or tourism.
	- `howToCome.html`: Guidance and tips on how to travel to the United States, including transportation options and entry requirements.
	- `routes.html`: Suggested travel routes, itineraries, and maps for exploring different regions of the United States.
Each page is styled with its own CSS file. The project includes a JavaScript file (`functions.js`) for interactive features and a `Fotos/` folder for images related to tourism and travel.

## Practice5
**Topic:** Portfolio showcase site.
Main files:
	- `index.html`: Portfolio homepage with sections for services, projects, and contact.
	- `style.css`: Main stylesheet for the site.
**fonts/**: Custom font files (`Montana.otf`, `Montana.ttf`) for unique typography.
**Fotos/**: Images for portfolio items, team, and branding.
**js/**: JavaScript file (`functions.js`) for interactive features and `package.json` for managing dependencies.

## Practice6
**Topic:** Conservation website focused on environmental education and awareness.
Main HTML pages:
	- `index.html`: Homepage introducing the conservation project, its mission, and key highlights.
	- `contact.html`: Page with contact information and a form for inquiries or support.
	- `education.html`: Educational resources and information about conservation topics, activities, and learning materials.
	- `projects.html`: Details about ongoing and completed conservation projects, including goals, results, and participation opportunities.
**css/**: Individual stylesheets for each page to provide a cohesive and informative design.
**img/**: Images related to conservation, nature, and educational content.
**script/**: JavaScript or other scripts for interactive features and enhanced user experience.
